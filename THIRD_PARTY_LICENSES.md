# Third-party licences

SceneDirector's own code is under the MIT licence (see `LICENSE`). This file lists
the third-party software it is built from, and the programs and services it talks
to at run time. It is generated by `scripts/third_party_licenses.py`.

## Not included in this repository

These are separate works. SceneDirector runs them or calls them; it does not ship them.

| What | Licence / terms | How it is used |
|---|---|---|
| [Blender](https://www.blender.org) | GPL-2.0-or-later | Started as a separate program (`blender -b`). `directorc/blender/runtime.py` runs inside Blender and uses its Python API; it is MIT-licensed, which is GPL-compatible. |
| [Python](https://www.python.org) | PSF-2.0 | Runs the backend and the CLI. |
| [FFmpeg](https://ffmpeg.org) | LGPL-2.1-or-later / GPL (build dependent) | Called as a separate program to encode MP4 animations. |
| [Microsoft Edge WebView2 Runtime](https://developer.microsoft.com/microsoft-edge/webview2/) | Microsoft software licence terms | Renders the desktop app's window on Windows. Installed with Windows, not redistributed here. |
| [Poly Haven](https://polyhaven.com/license) assets | CC0-1.0 | Models, HDRIs and textures downloaded on request into `projects/`. |
| [ambientCG](https://docs.ambientcg.com/license/) assets | CC0-1.0 | Materials downloaded on request into `projects/`. |
| [Pollinations.ai](https://pollinations.ai) | Service terms of Pollinations | Generates concept reference images on request. |
| [Tripo](https://www.tripo3d.ai) / [Meshy](https://www.meshy.ai) | Service terms of each provider | Optional paid image-to-3D, only with your own API key. |
| LLM providers (Ollama, Groq, Gemini, OpenRouter, ...) | Terms of the provider and model you choose | The director's language model, when you use the built-in agent. |

The image in `docs/media/` is a render made with SceneDirector from CC0 Poly Haven
assets (ArmChair_01, GreenChair_01, side_table_01, wood_floor).
